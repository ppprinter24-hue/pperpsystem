# Contributing

PP PRINTER & Advertising Accounting & ERP mein madad karne ka shukriya.

## Bug report / suggestion

Issue kholein aur likhein:
- kya karna chah rahe the aur kya hua
- kaunsa browser / device
- ho sake to screenshot (customer ya financial data hide karke)

## Pull Request

1. Repo fork karein aur chhoti, focused branch banayein.
2. Tabdeeli `index.html` mein karein (single-file app hai) aur browser mein Dashboard, Sales, Bank/Cash Book test karein.
3. Hisaab ke formulas (balance, ledger, trial balance) badalne se pehle purani aur nayi values compare karein.
4. PR description mein batayein kya aur kyun badla.

## Rules

- Asli customer ya business data kabhi commit na karein (backup JSON, screenshots, keys).
- Firebase rules / credentials se mutaliq tabdeeliyan alag PR mein bhejein.
- Style: existing compact style aur naming follow karein.
